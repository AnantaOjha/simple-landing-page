DEVELOPER TOOLKIT

Master Git, one command at a time.

Essential Git commands to make your development workflow faster.

01

Initialize Repository

Start tracking your project with Git.

git init
git status
02

Commit Changes

Save your changes with meaningful messages.

git add .
git commit -m "Update feature"
03

Branch Management

Create and switch between branches.

git switch -c feature
git branch -a
04

Push Code

Upload your changes to the remote repository.

git push origin main
05

Pull Updates

Get the latest remote changes.

git fetch origin
git pull origin main
06

Undo Changes

Restore files or reverse a commit.

git restore file.py
git revert HEAD
